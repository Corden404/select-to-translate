# 右键查词工具

Windows 11 上的英语阅读 AI 查词浏览器扩展。

当前处于产品定义 / 架构设计阶段。

## 已确定的核心体验

- Chrome / Microsoft Edge。
- 普通网页 + PDF。
- 选中英文单词或不超过 30 词的句子后自动查询。
- 快捷键控制自动查词总开关。
- 单词查询携带所在句作为语境。
- 句子查询携带前一句和后一句。
- OpenAI-compatible API。
- 流式输出。
- 选区附近悬浮卡片。
- 支持继续追问、重新生成、切换 Prompt、历史记录。
- 英式发音，发音 Provider 目标为有道。
- 速度优先。
