# 右键查词工具

Windows 11 上的英语阅读 AI 查词浏览器扩展，支持 Chrome / Microsoft Edge。

当前版本：`0.5.0`。MVP 产品定义中的核心功能已经实现，当前进入实际使用与兼容性打磨阶段。

## 已实现

- 普通网页英文划词自动查询。
- 自动 / 手动两种触发模式：自动模式划词即查；手动模式通过 `Alt + Shift + D`、右键菜单或独立设置页按钮查询来源页面当前选区。
- 可暂停当前网站的自动查词；自动模式默认忽略 input、textarea 和 contenteditable 等编辑区域，显式手动查询仍可使用。
- 扩展自带 PDF.js 阅读器，支持远程 PDF 与本地 PDF。
- 单词 / 短词组 / 句子识别，超过 30 个英文词不触发。
- 单词携带所在完整句子；句子携带前一句、当前句和后一句。
- OpenAI-compatible SSE 流式调用。
- DeepSeek、智谱 GLM、小米 MiMo、阿里云千问预设，以及自定义 OpenAI-compatible 接口。
- API 连接测试：设置页可直接使用尚未保存的 Base URL / API Key / Model 发起最小真实请求，显示成功/失败、耗时和简短返回。
- 中文悬浮卡片，默认黑夜模式，可切换亮色 / 跟随系统与字体大小。
- 点击卡片外自动关闭；图钉固定后仅手动关闭或全局停用时关闭；可拖动顶部状态区域调整浮窗位置，拖动时会限制在当前视口内。
- 多 Prompt 管理：新增、删除、启停、单词/句子/通用类型、默认路由、卡片内即时切换。
- Prompt JSON 导入 / 导出。
- 重新生成。
- 继续追问，并在当前卡片中扩展聊天。
- 新选区中止旧请求并结束旧会话；流式响应中途失败时保留已经生成的部分回答，并在卡片/历史中标记中断原因。
- IndexedDB 本地历史：URL、标题、上下文、Prompt 快照/版本、Provider、模型、首次回答与后续对话。
- 历史记录搜索、分页展示、删除和清空；搜索覆盖配置范围内全部保留记录，可关闭新历史写入，并按保留天数与最大条数节流清理旧记录。
- 默认发音 Provider 为 MiMo-V2.5-TTS，使用 `Mia` 英文女声并通过自然语言风格指令要求清晰、自然的英式英语词典发音；有道词典仅保留为英式音标备用来源，不下载有道音频。
- 可选自动语音解释：口语稿模型默认跟随主查词模型，也可单独选择已配置 Provider / Model，用更快或更便宜的模型生成简洁英文讲解，再使用 MiMo PCM16 流式 TTS 自动播放与重听。
- 发音 API 连接测试：可直接测试当前 MiMo TTS 或有道配置；MiMo 测试会生成一次极短 WAV 测试音频，有道测试只查询英式音标。
- 设置页可选择关闭悬浮窗口时是否停止声音；开启后会同时停止自动语音解释和浮窗内手动单词发音，关闭后声音可继续播放。
- 请求超时、认证/配额/限流/模型不存在/网络/协议错误分类。
- 公网模型/TTS Base URL 强制 HTTPS；仅 localhost / 回环地址允许 HTTP，本地开发仍可直连。
- LLM/TTS 流、音频和本地语音缓存均设置资源上限，异常大响应会主动中止。
- 每个模型平台分别保存自己的 API Key、Base URL 和模型名，切换 Provider 不丢自定义连接配置。
- 自动查词只接受真实用户输入事件，悬浮卡片使用 closed Shadow DOM，网页脚本不能直接驱动其请求控件。
- content script 到 service worker 的长度、30 词、来源 URL、上下文字段校验。
- iframe content script 支持。
- 设置页明确展示第三方数据发送与本地历史存储说明。
- 点击工具栏扩展图标会打开独立设置标签页；设置页记住来源标签页，因此“暂停来源网站”“手动查询来源选区”和“打开来源 PDF”不会误作用到设置页自身。

## 默认 Prompt

单词 Prompt 的主要说明使用中文，但“语境英文释义”明确要求英文。Prompt 可以在扩展独立设置页中完全自定义，也可以新增多个模板后在悬浮卡片里切换。

## 本地开发

```bash
npm install
npm run check
npm run e2e
```

- `npm run check`：TypeScript 类型检查 + Vitest 单元测试 + 构建。
- `npm run e2e`：构建后启动本机 Microsoft Edge，加载真实 Manifest V3 扩展并验证网页选词、流式对话、历史记录和 PDF.js 文本层选词。
- 构建产物位于 `dist/`。

Chrome / Edge 手工体验：

1. 执行 `npm run build`。
2. 打开浏览器扩展管理页并启用开发者模式。
3. 选择“加载已解压的扩展”，目录指向 `dist/`。
4. 点击工具栏中的“右键查词工具”，配置大模型 API。
5. 可先点击“测试模型 API”和“测试发音 API”确认配置可用，不需要先保存。
6. 保存后打开英文网页选词，或从独立设置页打开 PDF 查词阅读器。
7. `Alt + Shift + L` 切换查词总开关；`Alt + Shift + D` 手动查询当前选区，也可以在选中文字后使用右键菜单。


## PDF

文本型 PDF 使用 PDF.js 文本层复用与网页相同的选词链路。初次加载只读取第一页尺寸建立轻量占位，进入视口附近后才真正读取并渲染页面；缩放会尽量保持当前阅读页和页内位置。文本能力会抽样首页、四分位、中间和末页，避免仅因前几页是扫描封面就误判整份 PDF；扫描内容仍暂不支持 OCR。

## 发音

默认使用 `mimo-v2.5-tts`。MiMo 官方当前将 TTS 系列标注为限时免费；预置英文音色包括 `Mia`、`Chloe`、`Milo`、`Dean`。默认选择 `Mia`，并通过 user message 的自然语言风格指令要求清晰、自然、偏英式英语的词典式发音。官方并未把上述 voice ID 标注为英音或美音，因此口音要求来自风格控制，而不是硬编码的“英音音色”。

MiMo TTS API Key 可以单独填写；若主模型平台就是小米 MiMo，TTS Key 留空时会复用主 API Key。手动单词发音只在用户点击发音按钮时生成；若用户开启“自动语音解释”，口语稿可由主模型或单独选择的已配置模型生成，完成后再发送给 MiMo TTS 做流式播放。

有道智云词典仍保留为备用 Provider，但当前只使用 `ukPhonetic` 英式音标字段，不读取、不下载也不播放 `ukSpeech` 音频。

## 隐私

默认只把选中文字与必要上下文发送到用户配置的大模型 API。手动 MiMo 发音会在点击发音按钮后发送当前词；开启自动语音解释后，同一份选词与语境会额外发送给用户选择的口语稿模型生成英文语音稿，语音稿随后发送到 MiMo TTS。切换到有道时只查询词典英式音标，不下载音频。查询历史可完全关闭新写入，也可按保留天数和最大条数自动清理；数据只写入当前浏览器的 IndexedDB。API Key 与发音服务密钥不会发送给网页 content script。
