划词即查 · 上下文理解 · 自定义大模型

快捷键：Alt + Shift + L。

API 配置

连接测试会使用当前表单值发送一个极小的真实模型请求，可能产生少量 Token 消耗；无需先保存。

界面设置

历史记录

关闭后不再写入新的历史；已有记录不会因此自动删除。启用时会按时间和数量上限自动清理旧记录。

Prompt 管理

可用变量：{{selection}}、{{context}}、{{pageTitle}}、{{pageUrl}}

发音设置

官方没有把 Mia / Chloe / Milo / Dean 标注为英音或美音；默认通过自然语言风格指令要求清晰自然的英式英语词典发音。MiMo-V2.5-TTS 当前官方标注为限时免费。

备用方案：仅查询有道智云词典的英式音标，不下载或播放有道音频。

MiMo 测试会实际生成一次极短测试音频；有道测试只查询单词 hello 的英式音标。无需先保存。

自动语音解释

仅对单词/短词组生效。展示解释与全英文口语讲解会并发请求当前大模型；口语稿完成后使用 MiMo TTS 自动播放。新的查词请求会立即停止上一段语音。

默认使用 1.0× 自然音调。流式 Web Audio 的倍速会同时改变音调；首次播放和“重听讲解”都会使用这里的速度。

这个 Prompt 只负责生成适合直接听的全英文老师讲解，默认要求使用常见词和短句，尽量避免高级词汇；不影响浮窗里的结构化解释。

自动语音解释固定使用上方 MiMo TTS 配置与音色；即使单词发音服务选择有道或关闭，也会使用 MiMo TTS。

隐私说明

查词时，仅把你选中的英文文本和所需的前后文发送到你配置的大模型 API。开启自动语音解释后，同一份选词与语境会额外并发发送给当前大模型生成一段自然口语讲解，随后生成的讲解文字会发送到小米 MiMo TTS；新的查词会停止上一条语音任务。手动 MiMo 发音会把当前词发送到 MiMo；选择有道时只查询词典英式音标，不下载有道音频。查询历史可关闭，并可按保留天数与条数自动清理；数据只存储在本机浏览器的 IndexedDB，不上传到本项目的服务器。API Key、发音服务密钥、模型连接参数、展示 Prompt 和语音 Prompt 正文只保留在扩展受信任上下文；网页 content script 只接收界面所需的公开设置，不接触任何密钥。
